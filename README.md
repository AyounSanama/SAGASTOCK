# SAGASTOCK

Plateforme professionnelle de gestion pharmaceutique et médico-logistique pour
les ONG, programmes de santé et formations sanitaires.

## Produits à livrer

- Application Flutter pour Android et iOS, utilisable hors connexion.
- Portail Web d'administration et de pilotage.
- API REST Laravel sécurisée.
- Base centrale PostgreSQL et base locale SQLite chiffrée.
- Moteur de synchronisation bidirectionnelle, audit et rapports.

## État du projet

Le projet est en phase 1 : spécifications et architecture. Les règles
pharmaceutiques critiques et le modèle de données doivent être validés avant la
création des migrations métier.

Les documents de cadrage se trouvent dans [`docs`](docs/README.md).
